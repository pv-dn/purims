## 基本導入に含むもの

| 内容 | 備考 |

| 納品書発行・発行履歴・客先／品目マスタ・ログイン・自社情報・A4印刷 | |
| 入出荷台帳（「入」数量入力） | 追加費用なし（サービス） |
| 会社名マスタ（伝票印刷は店舗名のみ） | |
| 客先グループ（配送便の区分） | |
| ロット番号（台帳で都度選択→伝票反映・荷造り照合） | 実装は基本範囲。見積のオプション枠は据え置き |
| マスタのCSV読込／手入力（導入後の運用は乙） | |
| 請求系マスタ項目の表示設定（最低保証・配送費等） | 請求機能利用時 |
| クラウド保存・JSONバックアップ・スタート／運用ガイド | |

## 見積書に書いておく一文（例）

> 本見積は、基本導入および記載のオプションをすべて含む構成です（初期費用税別200,000円）。  
> 月額サポートは税別10,000円とし、期間は別途取り決めます。  
> データはFirebase（Googleのクラウド上のデータ置き場）に保存します。導入当初は提供者側のFirebaseを使い、御社でのFirebase登録は不要です。  
> 後日、御社のFirebase等へ移管する場合は、時期・作業範囲・費用を都度ご相談とします。
