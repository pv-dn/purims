甲および乙は、乙が甲に提供する伝票発行システムおよび入出荷台帳アプリケーション（以下総称して「本システム」という。）の利用等に関し、次のとおり契約（以下「本契約」という。）を締結する。

第1条（目的）

本契約は、乙が甲に対し本システムの利用を許諾し、初期導入およびサポート等の条件を定めることを目的とする。

第2条（定義）

  1. 「本システム」とは、画面上「Primus 伝票発行システム」等の名称で提供される伝票発行用Webアプリケーション、およびこれに付随する入出荷台帳アプリケーションをいう。
  2. 「見積書」とは、本契約に先立ち乙が甲に提示した導入費用およびオプション等の見積書類をいう。
  3. 「注文書」とは、甲が見積書の内容に基づき乙に対して発注の意思を表示する書類（電磁的方法によるものを含む。）をいう。
  4. 「別紙」とは、本契約末尾の「別紙（取引内容）」をいい、本契約の一部を構成する。

第3条（契約の成立）

  1. 本契約は、甲が乙に対し注文書を交付し、かつ甲乙が本契約の内容に合意し、記名押印（またはこれに準ずる電磁的な合意）をしたときに成立する。
  2. 注文書の記載と本契約または見積書の記載に相違がある場合は、甲乙協議のうえ確定する。協議が整わない事項については、本契約および見積書の記載を基準とする。
  3. 本契約に定めのない事項で見積書または注文書に定めのある事項は、本契約に反しない限り、その定めに従う。

第4条（納品物）

乙が甲に納品する物は、次のとおりとする。

  1. 本システムを利用するために必要な環境（伝票アプリケーションおよび台帳アプリケーションのURLその他これに準ずる利用手段）
  2. 初期設定に関する案内（ログイン方法および基本操作の説明を含む。）
  3. スタート・運用ガイド（導入手順および日常運用に関する説明資料）
  4. 別紙に記載した初期設定、カスタマイズおよびオプション機能

ソースコードの引渡しは、原則として行わない。必要がある場合は、別途書面により合意する。

第5条（納品および検収）

  1. 乙は、前条の納品物の提供が完了したときは、甲に対し納品書を発行する。
  2. 甲は、納品書受領後、〔　　〕日以内に本システムの利用可否を確認し、乙に対し確認の結果を通知する。当該期間内に甲から書面（電磁的方法を含む。）による異議がないときは、検収が完了したものとみなす。
  3. 検収完了をもって、本システムの初期導入は完了したものとする。
  4. 検収前に発見された本システムの明らかな不具合については、乙が無償で修正する。ただし、甲の指示に基づく仕様変更、甲の環境に起因する事象は、この限りでない。

第6条（利用許諾の範囲）

  1. 乙は甲に対し、本契約の有効期間中、本システムを甲の業務目的の範囲内で利用することを非独占的に許諾する。
  2. 利用の範囲は、原則として甲の一法人（一組織）に限る。
  3. 甲は、本システムを第三者に再販売、再配布、賃貸、貸与し、または利用許諾してはならない。
  4. 本システムに係るログイン情報の管理は、甲の責任において行う。
  5. 甲は、伝票等に表示する自社名、住所、連絡先その他の表示内容を、本システム内の設定機能により管理する。当該表示内容の正確性についての責任は、甲が負う。

    2. (2) 月額サポート料

  6. 別紙および見積書に含まれない追加改修、追加オプションその他の作業は、別途見積のうえ実施する。

  1. 別紙に記載した範囲を超える改修は、追加の見積および合意を要する。

第9条（サポート）

  1. 乙は、月額サポート料の対象期間中、次の事項に対応する。
    1. (1) 本システムの操作方法に関する問い合わせ
    2. (2) 本システムに起因することが明らかな不具合の修正
    3. (3) 軽微な運用上の相談
  2. 次の各号に該当する事項は、サポートの対象外とし、または別途対価を要する。
    1. (1) 甲の使用する端末、プリンタ、ブラウザ、ネットワークその他甲の環境に起因する問題
    2. (2) 甲が依頼する仕様変更または追加開発
    3. (3) 甲の操作誤り等によるデータの消失に係る復旧（乙は可能な範囲で協力するが、復旧を保証しない。）
  3. サポート期間の終了後における継続対応は、更新合意または都度の見積による。

第10条（データおよびクラウド）

  1. 本システム上に保存される業務データ（客先、品目、発行履歴等）に関する権利は、甲に帰属する。
  2. 乙は、サポートおよび障害対応に必要な場合を除き、甲のデータを本契約の目的外に利用しない。
  3. 甲は、重要データについて、本システムが提供するバックアップ機能等を用い、適宜バックアップを行うものとする。乙は保全に努めるが、完全な保全を保証しない。
  4. 導入当初、本システムのデータは乙が用意するクラウド環境（Firebaseその他これに準ずるサービスを含む。）に保存する。甲は、利用URLおよびログイン情報により本システムを利用でき、甲自身による当該クラウドのアカウント登録は必須としない。
  5. 甲乙合意のうえ、甲が用意するクラウド環境へデータを移管し、接続先を変更することができる。移管の時期、作業範囲および費用は、都度見積または別途合意による。
  6. 本契約終了時、甲から請求があった場合、乙は合理的な範囲でデータのエクスポートおよび移管に協力する。

第12条（秘密保持）

甲および乙は、本契約の履行に関し知り得た相手方の営業上または技術上の秘密を、相手方の事前の同意なく第三者に開示または漏洩してはならない。ただし、法令に基づき開示が求められる場合は、この限りでない。

  6. 本契約終了後、乙は合理的な期間の経過後、甲向けの利用環境を閉鎖することができる。

第14条（協議および管轄）
